# TraceNote 第一版产品与开发计划

## 目标

面向访谈研究者和用户研究团队，支持“读原文—贴标签—人工确认—修订标准—复核—追溯证据”。求职展示重点是可纠正、可追溯、可评估的 AI 工作流。

研究问题：人们为什么当前放弃公共交通？先支持一个小型标签体系和文本材料。不是自动推断心理、生成代表性引文、因果估计或全领域研究平台。

## 页面与验收

标注页：P001 可以用“晚到二十分钟”作为可靠性证据。伪造的文本不能保存。P004 可以零标签确认；P005 以“含义不明确”留待复核。

规则页：给可靠性排除规则补充“已改善的历史问题不算当前退出原因”。显示旧值、新值与修改原因。发布 v2 后，所有已审材料（包括零标签判断）重新复核，以覆盖潜在漏标；初版采用保守全量策略，不声称智能影响分析。

汇总页：只计当前规则版本下最近一次已确认判断。旧版、歧义和待标注材料不进入汇总；每条引文有原文 ID。同段重复保存不重复计数。

## 数据模型

- Document: id, name, fictional。虚构摘录集合不把相邻片段当同一访谈上下文。
- Paragraph: id, documentId, text。原文导入后不变，ID 在当前项目递增，不重用。
- CodebookVersion: id, createdAt, reason, labels[]。发布形成快照。
- Label: id, name, definition, include, exclude。
- Review: id, paragraphId, versionId, annotations[], note, status, source, createdAt。
- Annotation: labelId, quote, start, end。JavaScript UTF-16 坐标；跨语言后端必须明确转换，不能直接使用 Python Unicode 索引。
- 状态派生：无记录 pending；版本不一致 stale；否则使用最近判断 confirmed / ambiguous。

每次保存均追加 Review；不删除或覆盖旧决定。localStorage 写入失败时不报告成功。

## M2：真实 AI 与本地服务

1. 加入 TypeScript 类型与本地服务、SQLite 持久化、JSON 恢复与数据迁移。
2. 通过服务端环境变量配置模型凭据；浏览器不保存 API 密钥。
3. 实现固定 codebook 版本的模型任务，分别保存建议与人工决定；明确状态 proposed / accepted / modified / rejected。
4. 校验标签 ID、引文位置、输出结构；失败进入复核队列，不自动补造证据。
5. 根据人工纠正提出可审核的规则修改建议，记录触发证据；人工发布后才生效。
6. 加入任务状态、失败重试、重复请求保护和规则版本冲突检测。

不假定任何厂商当前 API。接入时查阅官方文档，再固定 SDK / API 版本。

### 拟定模型输入输出

输入：researchQuestion、scope（当前退出原因）、codebookVersionId、labels、paragraph{id,text}、同一访谈的有限上下文。材料中的指令仅当作研究数据。

输出：paragraphId、codebookVersionId、annotations[{labelId,quote}]、reviewReasons[]、abstainReason。服务端验证精确子串并确定坐标；重复出现的片段要求更明确证据或人工定位。模型生成的解释不能冒充原文。任务返回时若规则已更新，仍保留其原版本并排队复核。

规则建议：baseVersionId、labelId、proposedChanges、triggerReviewIds、rationale；由用户编辑/接受/拒绝。暂不自动修改规则，也不自动重新确认人的判断。

## M3：评估和 GitHub 展示

按完整访谈划分开发集与保留测试集，固定 codebook 后评估；不能让同一访谈的相邻段落分散进两组。当前六段只是交互演示，不是独立测试集。

基线：同一个模型、同一份规则和材料直接提示标注。比较多标签 micro/macro precision、recall、F1，以及各标签误差。无标签段落独立报告。衡量精确引用合法率及人工判断的证据支持率；精确匹配不等于支持标签。

使用多人独立标注记录分歧和裁决规则，报告哪些边界仍有争议。没有第二位标注者时明确说明，不能编造一致性指标。测量相同任务的复核耗时，控制学习效应和顺序；没有实测不宣称节省时间。

发布材料：README、截图/视频、架构图、启动说明、示例数据、真实评估结果、限制、许可证选择。发布前确认仓库中没有密钥和私人访谈。公开演示使用虚构材料和调用额度限制。
